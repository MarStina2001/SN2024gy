# SN2024gy
Calibration of the spectra of SN2024gy

The main work done is in clean.ipynb where you can see that something must be done on Iraf terminal and not on pyraf.\
I suggest you to look and run the script in the following order:\
bias.ipynb\
flat.ipynb\
clean.ipynb\
lamp.ipynb\

If you download and run this project in a Windows folder (with WSL it's something like mnt/c/...) you could have some troubles cause the symbol ":" in files names is not recognized and so replaced. I suggest you to replace it with "_" in both file names and file names lists.
